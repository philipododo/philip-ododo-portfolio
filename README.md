# Philip Ododo · Portfolio

Personal portfolio site for Philip Ugbede Ododo: customer experience, business analysis, analytics, and technology.

**Live site:** https://philipododo.github.io/philip-ododo-portfolio/

## What's here

| File | Purpose |
|---|---|
| `index.html` | The whole site: one static page with inline CSS and JavaScript, no build step |
| `philip-ododo-headshot.jpg` | Headshot shown in the hero card |
| `innovest-illustrative-dashboard.jpg`, `telstra-illustrative-dashboard.jpg` | Illustrative dashboards (sample data only, not actual company data) |
| `Philip_Ugbede_Ododo_Resume.pdf` | Résumé behind the "Download résumé" button |

## Editing and deploying

Edit `index.html` and push to `main`. GitHub Pages redeploys automatically within a minute or two. To preview locally, open `index.html` in a browser.

The animations respect the visitor's "reduce motion" setting.
